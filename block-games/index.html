Questions

How do I block Steam or games on Windows?

Install Hushblock for Windows, add Steam and your games to the block list, and start a focus session or schedule. Blocked apps close as soon as they open.

Can I limit games to 1 hour a day?

Yes. Set a daily limit for any app; once it's used up, the app is blocked until tomorrow.

Is the game blocker free?

Blocking up to 3 apps is free. Pro makes it unlimited and adds strict mode and password protection.
